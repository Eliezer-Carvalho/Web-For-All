<h1> Description </h1>

<p> <b> The Web is the most widely used space in the world!</b> However, there is a lot of misinformation regarding the emergence of the Web and its history.

<p> This repository emerged as part of the development of a landing page that navigates the history of the web since its inception. <br>

It answers questions such as: <br>
  <ul> 
<li> <b> What types of websites are there? </b> </li> 
<li> <b> What types of hosting are there? </b> </li> 
<li> <b> What is a domain? </b> </li> 
<li> <b> What programming languages do I need to learn to enter the world of Web Development? </b> </li> 
  </ul>
And much more..
